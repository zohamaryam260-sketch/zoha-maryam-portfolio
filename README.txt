ZOHA MARYAM — EDITABLE PORTFOLIO WEBSITE

How to edit:
1. Open index.html in Chrome to preview the website.
2. Open index.html in Notepad, VS Code, or another text editor to change headings, paragraphs, button text, and links.
3. Open styles.css to change colors, fonts, spacing, and layout.
4. Replace images inside assets/ with your own images. Keep the same filenames if you want to avoid changing the HTML.
5. The main logo is assets/logo.png.
6. Portfolio images are assets/project-5.png through project-24.png.
7. Keep index.html, styles.css, script.js, and the assets folder together.

Quick text locations in index.html:
- Browser title: <title>
- Hero heading: Creative Graphic Designer
- Hero paragraph: first paragraph in #home
- Services: section with id="services"
- Portfolio: section with id="portfolio"
- Contact: section with id="contact"

To change the Hire Me contact destination, find the links containing #contact and replace with your email, Fiverr profile, or another URL when ready.

This is a normal editable HTML/CSS website; it is not a Google Sites template.
